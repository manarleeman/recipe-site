Ocean of Recipe
Overview

Ocean of Recipe is a simple and intuitive web application that allows users to search for recipes and explore detailed cooking instructions for their favorite meals. The app integrates with TheMealDB API to fetch real-time recipe data and dynamically display the results in an engaging, user-friendly interface.

Features

Search for recipes by meal name

Display search results with images and clickable links

View detailed recipe instructions, ingredients, and video tutorials

Fully responsive design optimized for both mobile and desktop users

Project Structure
recipe-finder/
│-- index.html      # Homepage with search functionality
│-- recipe.html     # Recipe details page
│-- index.js        # JavaScript for handling search and fetching recipes
│-- recipe.js       # JavaScript for displaying recipe details
│-- styles.css      # Styling for the entire project
│-- README.md       # Project documentation

Installation

Clone the repository:

git clone https://github.com/your-username/recipe-finder.git


Navigate to the project directory:

cd recipe-finder


Open index.html in your browser to launch the application.

Usage

Enter a meal name in the search bar on the homepage.

Click the Search button to find matching recipes.

Select a recipe to view its full details, including ingredients, cooking steps, and a video tutorial.
